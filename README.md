# 작은 친구 · v0.4.3

Windows Tauri 앱 소스입니다. `src-tauri/target`, `node_modules`는 포함하지 않습니다.

## 실행
기존 실행 중인 앱을 트레이 메뉴의 종료 또는 터미널 Ctrl+C로 완전히 종료하세요.
새 폴더에 압축을 풀고 package.json이 있는 위치에서 실행합니다.

```powershell
npm install
npm run dev
```

Rust / Visual Studio C++ Build Tools / WebView2가 필요합니다.
설정 창 상단의 0.4.3 표시로 적용 여부를 확인하세요.
설정 창을 닫으면 트레이 메뉴에서 다시 열 수 있습니다.
`npm run browser`는 설정 디자인을 확인하는 웹 미리보기이며 Windows 입력 통과는 테스트하지 못합니다.

## 변경
- 전체 화면 오버레이는 기본 숨김 + 네이티브 클릭 통과, 춤 중에도 클릭 통과
- 저수준 키보드/마우스 훅 제거. 40ms 간격 상태 조회, 감시할 때만 이벤트 전달
- 모든 캐릭터 창 그림자 제거, HTML/배경 투명 처리
- 캐릭터 이미지 알파를 96x96 마스크로 전달하여 빈 영역 클릭 통과 (윤곽 판정은 격자 근사)
- 네이티브 창 드래그; DPI 배율에 맞춘 좌표 판정
- 우사기 고개: 하앙~~? + usagi-awake.mp3
- 걸렸을 때: usagi-dance.mp3 (7.392초), 춤 약 7.6초
- GIF 원본 프레임/타이밍을 아틀라스로 추출해 한 캔버스에서 24fps로 표시
- 우사기 60 / 모몽가 70 / 하치와레 60 / 치이카와 60. 위치는 매번 랜덤
- 캐릭터 선택 / 볼륨 / 음소거 / 크기 / 일시정지 / 출현 간격 / 미리보기
- 기본 출현 간격 3~6분. 설정 자동 저장
- Ctrl+Shift+U 고개 들기, Ctrl+Shift+Q 종료
- 마우스와 키보드 입력 모두 감지합니다. 입력 내용은 저장하지 않습니다.

## 확인 범위
JavaScript 문법, 파일 참조, 설정 JSON, 음원 파일, ZIP 무결성을 확인합니다.
Windows 네이티브 빌드/실행 및 실제 CPU 측정은 이 환경에서 검증하지 못했습니다.

추가 검증: `npm test`는 DOM/네이티브 API를 모의한 상태 전이·음원 연결 회귀 테스트입니다. 실제 Windows 클릭 통과 테스트는 아닙니다.


## WebView2 시작 오류(0x8007139F)
먼저 앱의 모든 프로세스를 닫고 `src-tauri/target` 폴더를 삭제한 뒤 `npm run dev`를 다시 실행합니다. 시작 로그에 pet/settings WebView 생성 시점이 찍혀 어느 창에서 멈추는지 확인할 수 있습니다. 계속 실패하면 Windows 설정의 설치된 앱에서 Microsoft Edge WebView2 Runtime을 복구하거나 최신 런타임을 설치하세요.
